
# My PORTFOLIO
A one-page personal portfolio website built with HTML5 and CSS3 , created as a university assignment.

 # About the Assignment
The task was to design and build a simple one-page portfolio that introduces the student, shows their skills and projects, and gives a way to get in touch. The page is made using only HTML for structure and CSS for styling, to practise page layout, typography, responsive design and clean, readable code.

# Sections
The website is a single page. The navigation bar at the top scrolls smoothly to each section:
Section	What it contains

-Home	Name, short introduction and a code-style card written as a C++ class
  
-About	A short summary about me and what I am looking for

-Skills	C++, Python, HTML, Java, MS Excel, SQL, Mongo DB, MS Office, plus languages (English, Urdu)

-Projects	Four academic projects with the technologies used

-Education	BS Computer Science, FSc Pre-Engineering and Matric with Science

-Contact	Email, LinkedIn and city

# Projects Featured
•	Online Banking System (Python, C++)

•	Land Management System (Java, SQL, JDBC)

•	Data Cleanser App (Python, Pandas)

•	Algorithm Visualization (Python, Java, C++)

# Technologies Used

•	HTML5 for semantic page structure (header, nav, main, section, article, footer)

•	CSS3 for styling, including: 

o	CSS variables for the colour palette

o	Flexbox and Grid for layout

o	Media queries for mobile-friendly design

o	Sticky navigation bar and smooth scrolling

o	Respect for the "reduce motion" setting
